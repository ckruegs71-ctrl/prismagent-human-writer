# Contextual editing checks

These are editorial checks, not AI-authorship signals. Use only those that affect the draft.

| Pattern | What to examine | Better decision |
|---|---|---|
| Generic opener | Could this opening introduce almost any company or topic? | Lead with the actual subject, question, or useful fact already supplied. |
| Inflated vocabulary | Does a plain verb preserve the exact meaning? | “Utilize the form” can become “use the form.” Keep technical terms such as financial leverage and robust regression. |
| Unsupported importance | Does “revolutionary,” “unmatched,” or “game-changing” have evidence? | Remove the claim or ask for support; do not substitute a new unverified benefit. |
| Empty contrast | Does “not just X, but Y” identify a real distinction? | State the point directly if the setup adds nothing. Keep a meaningful comparison or correction. |
| Forced triad | Are three items distinct and necessary? | Keep useful lists of three. Remove redundant items without inventing a fourth to break a pattern. |
| Vague attribution | Who says “experts agree”? | Use an existing source, ask for one, or flag the claim. Never create a citation. |
| Pseudo-analysis | Does a phrase such as “highlighting its importance” explain anything? | State a supported consequence or cut the empty commentary. |
| Synonym cycling | Is the same service renamed every paragraph? | Use a consistent term when it improves comprehension. |
| Repetitive structure | Does every paragraph use the same setup, reveal, and takeaway? | Combine duplicate thoughts and follow the argument. Do not impose random variation. |
| Stage directions | Is “let's dive in” or “here's what you need to know” delaying the point? | Cut it when expendable; preserve an intentional spoken transition. |
| Manufactured emotion | Is a memory, fear, or victory being added only to create personality? | Use the author's supplied experience or leave it out. |
| Over-explanation | Does the next sentence repeat what an example already shows? | Keep necessary explanation; remove redundant interpretation. |
| Generic ending | Does the final line introduce a useful next step? | End on the actual point or intended action, not a manufactured life lesson. |
| Engagement bait | Is a question disconnected from the content? | Ask the real question if supplied; preserve a requested CTA. |
| Formatting excess | Do headings, bold labels, hashtags, or emoji help this channel? | Simplify based on the intended format; no universal quota or platform-performance claim. |
| Accidental chat artifacts | Does the draft contain an assistant preamble or leftover placeholder? | Remove stray framing from publishable prose. Preserve intentional discussion of AI, disclosure, quotations, and placeholders the user wants. |

## Practical channel choices

- **Email:** make the request, deadline, and next action easy to find. Preserve courtesy when it serves the relationship.
- **LinkedIn or Instagram:** keep the writer's actual point of view. Avoid adding a founder story, income claim, or customer anecdote that was never supplied.
- **Video script:** read for speakable phrasing. Fragments and conversational transitions can be useful.
- **Article or documentation:** preserve structure, terminology, citations, and necessary qualifications. Do not turn technical documentation into a personal essay.
- **Fiction:** distinguish line editing from developmental editing. Consult the research reference before applying narrative-specific observations.

## Conflicting preferences

Resolve style conflicts using the user's current request, their relevant voice profile or samples, then the draft and channel. Truthful scope and faithful quotations remain constraints. A no-em-dash house style does not authorize changing a title or quote; a request for specificity does not authorize invented numbers. If two explicit requirements cannot both be satisfied, explain the narrow conflict instead of silently discarding one.
